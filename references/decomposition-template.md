# 八维拆解模板（decomposition template）

对每张图按以下八个维度逐项分析。每项输出"可执行描述"——另一条 AI（或另一个人）只看文字就能复现的程度。

## 1. 主体（Subject）
- 谁/什么在画面里：数量、年龄感、姿态、穿着、关键识别特征
- 主体与画面的关系：占画面比例、视觉重心位置
- 例：❌"一个女人" → ✅"一位二十多岁东亚女性，侧身坐姿，短发，穿米白色oversize西装，占画面左侧约 1/3"

## 2. 场景（Setting）
- 在哪里、什么时间、什么天气/氛围
- 前景/中景/背景各有什么
- 例："深夜的街边卤菜店，暖黄灯光从店内溢出，背景虚化的城市夜景光斑"

## 3. 构图（Composition）
- 景别：特写 / 近景 / 中景 / 全景 / 大全景
- 机位：平视 / 俯拍 / 仰拍 / 等轴测（2.5D）/ 顶视
- 构图法则：居中 / 三分法 / 对称 / S 曲线 / 框架式
- 留白：位置与比例（海报类必写，如"左上 1/3 留白用于标题"）
- 画幅比例：1:1 / 3:4 / 9:16 / 16:9 …

## 4. 光影（Lighting）
- 光源类型与方向：柔光箱 / 自然窗光 / 霓虹 / 逆光轮廓光
- 硬光还是软光、阴影特征、色温冷暖
- 特殊光效：体积光、光斑、反射、发光体

## 5. 色彩（Color）
- 主色调 + 点缀色（尽量给出具体颜色名：不是"好看的颜色"，是"橙红渐变 + 米白底 + 深灰文字"）
- 饱和度/明度倾向：低饱和胶片感 / 高饱和商业感
- 色彩关系：互补 / 邻近 / 单色

## 6. 风格媒介（Style & Medium）
- 写实摄影 / 3D 渲染（C4D 质感/黏土/盲盒）/ 扁平插画 / 手绘水彩 / 国风水墨 / 像素风…
- 可参考的具象锚点（品牌、艺术家、电影）——只写真能看出来的，禁止堆砌
- 质感细节：胶片颗粒 / 纸纹 / 光泽度 / 景深

## 7. 图中文字与字体（Text & Typography）★海报类核心
- **逐字转写所有可见文字**，标明每段文字的：
  - 内容（原文，含标点）
  - 位置（顶部居中 / 左下角…）
  - 层级（主标题 / 副标题 / 正文 / 装饰小字）
  - 字体特征：手写体 / 衬线 / 无衬线粗黑 / 毛笔字 / 像素体…
  - 颜色与特效：描边 / 阴影 / 渐变 / 镂空
- 读不清：`[看不清]`；推测内容：`[不确定：xxx]`

## 8. 情绪氛围（Mood）
- 一个词说不清就写一句通感描述："像初春下午喝茶的松弛感"比"温馨"更可执行
- 这张图"让人想做什么"（想买？想点进去？想转发？）——反推商业图时这层最关键

---

## 输出格式（拆解表）

| 维度 | 观察结果 | 置信度 |
|---|---|---|
| 主体 | … | 高/中/低 |
| 场景 | … | … |
| … | … | … |

置信度低的部分在最终提示词里降级处理（删掉或标注可选），不要硬编。
